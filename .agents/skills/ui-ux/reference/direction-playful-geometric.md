# Direction — Playful geometric

**Content fit:** education, kids, games, creative tools, community platforms, side projects.
**Not when:** the audience is purchasing compliance, security, or enterprise reliability.

## Skeleton

```
┌──────────────────────────────────────────┐
│ ███ colour block ███   headline          │
│                        ┌───────────────┐ │
│   ● ◼ ▲ shapes         │ product/illust│ │
│                        └───────────────┘ │
├──────────────────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐                 │
│  │ 2x  │ │ 1x  │ │ 1x  │  uneven weights │
│  └─────┘ └─────┘ └─────┘                 │
└──────────────────────────────────────────┘
```

Sections: colour-block hero → asymmetric bento (justified by different content weights) → one interactive demo → colophon.

## Type

- Display: chunky — Bricolage Grotesque 800, Clash Display, Fraunces Black, or a rounded sans at 48–80px.
- Body: rounded or humanist sans at 16px, 1.6. Sentence case, friendly but not childish.
- One family can do both if weight contrast is strong.

## Color

- One neutral field plus three brights (primary, secondary, highlight) used as blocks.
- Hard edges or one consistent radius — not mixed.
- Colour blocks carry hierarchy; they are not decoration behind text.

## Texture

Geometric shapes (circle, square, triangle, arc) as a system, thick 2–3px outlines, sticker-like accents, simple SVG illustration.

## Motion

Springy and short: 160–220ms scale/translate on hover, one 300ms hero entrance. Bounce only on interactive elements, never on text.

## Signature

A shape system that recurs — the same circle/square/arc used as bullets, avatars, section markers, and empty states.

## Avoid

Muted corporate palettes, thin serifs, dense tables, glass, gradient text, three identical cards, over-animation.
