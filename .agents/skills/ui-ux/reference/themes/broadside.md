# Theme — Broadside

**Material:** grained buff stock; near-black ink; Six Caps and Bevan wood capitals over Archivo Narrow; ink rules at one point or five, one vermilion.
**Not when:** the page needs an image more than a sentence, or the audience reads on a phone in one hand.

## Tokens

```
paper      oklch(88% 0.030 88)      paper-2   oklch(92% 0.022 88)
ink        oklch(18% 0.010 60)      muted     oklch(48% 0.015 60)
accent     vermilion 33 · chroma 0.18          accent-ink  oklch(97% 0.008 33)
edges      radius 0 · depth none · rules 1pt and 5pt, nothing between
```

## Type

- Display: Six Caps at 100–240px, leading 0.86, capitals. Bevan for a second voice, never both in one line.
- Body: Archivo Narrow 400 at 17px / 1.5, 44–58ch, two columns after the hero.
- Labels: body face a step smaller, sentence case, untracked — never letter-spaced capitals.
- No weight between 400 and 900.

## Surfaces

- Grain at 5% over the whole ground; no gradients.
- Rules are structural: a 5pt rule opens, a 1pt hairlines separates. Both run the full measure.
- Photographs appear as a single duotone block, cropped hard, no radius, no caption box.

## Range

- An announcement set as three stacked lines, each a different size.
- A price list: name left, figure right, dotted leader between, 1pt rules.
- A pull quote in Bevan across four columns, the rest of the page narrow.

## Motion

Nothing enters. Hover solidifies a 1pt rule to 3pt in 120ms; that is the whole motion budget.

## Voice

Declarative, dated, no adjectives. It reads like a printed notice, not a website.

## Signature

The 5pt rule running the full measure above wood capitals, with the body text set narrow beneath it.

## Avoid

Rounded corners, blurred shadows, wide body text, colour photography, a third rule weight, centred hero.

## Pairs with

Poster stack · Editorial columns · Full-bleed band
