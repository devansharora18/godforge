# Direction — Luxury

**Content fit:** high price, craft, hospitality, fashion, hardware, a single object.
**Not when:** the page must compare plans or explain a workflow.

## Skeleton

```
┌──────────────────────────────────────────┐
│                    wordmark        menu  │
│                                          │
│            one enormous line             │
│                                          │
├──────────────────────────────────────────┤
│ ████ full-bleed image, bleeds all edges █ │
├──────────────────────────────────────────┤
│   (vast margin)      two sentences       │
│                      small cap label     │
└──────────────────────────────────────────┘
```

Sections: image-led hero → one statement → detail diptych → single CTA → colophon. Fewer than five sections.

## Type

- Display: a refined serif at large size — Canela, Ogg, Fraunces 300, Cormorant. One line, wide.
- Body: the same serif at 15px, or a quiet grotesk. Labels in wide-tracked caps (0.24em).
- Sizes are extreme: 96–160px display, 11px labels, little in between.

## Color

- Bone, ivory, ecru, or black. One deep tone (oxblood, forest, navy) plus photography.
- No accent colour competing with the image. No badges, no urgency.

## Texture

Real photography with a considered crop, generous negative space, thin rules, a small mark. No decorative SVG.

## Motion

Slow and sparse: 800–1200ms image scale from 1.04 → 1, 600ms type fade. Nothing moves on hover except an underline.

## Signature

One oversized line of type and an image that bleeds past the container. The confidence is in what is missing.

## Avoid

Discount energy, counts, multiple CTAs, icon rows, badges, gradients, more than two colours, centred body copy.
