# Theme — Brutal

**Material:** near-white poster stock; near-black ink as 3px rules, boxed cells and solid fills; uppercase Libre Franklin 900 over its 400; zero radius, one acid-yellow fill.
**Not when:** the page sells calm, care, or a premium object.

## Tokens

```
paper      oklch(95% 0.004 95)      paper-2   oklch(99% 0.002 95)
ink        oklch(15% 0.005 60)      muted     oklch(45% 0.004 60)
accent     yellow 105 · chroma 0.19            accent-ink  oklch(18% 0.02 105)
edges      radius 0 · depth none · rules 3px solid, everywhere
```

## Type

- Display: Libre Franklin 900, uppercase, leading 1.0, −0.03em, 40–96px.
- Body: Libre Franklin 400 at 17px / 1.55, 55–68ch. The two weights never swap roles.
- Labels: the body face at 400, a step smaller, sentence case, untracked. Capitals belong to the display, not to labels.
- No italic anywhere.

## Surfaces

- Every box is a 3px ink rule with no radius; cells butt against each other with no gap.
- One acid-yellow fill per screen, used as a field behind a single fact.
- No shadows and no depth: hierarchy comes from weight, fill and rule.
- Photographs only as high-contrast black and white, inside a ruled cell.

## Range

- A comparison table where each cell is a ruled box.
- A number set at 96px on the yellow field, with one line of prose beside it.
- A list of rules, each numbered in the display face, no icons.

## Motion

None on entry. Focus and hover are the only states that change, and they change instantly.

## Voice

Short, blunt, imperative. Sentence fragments are allowed; filler is not.

## Signature

The ruled cell: every block of content is boxed by 3px of ink with square corners, so the page reads as one grid of printed cells.

## Avoid

Rounded corners, soft shadows, gradients, a second accent, lowercase display, centred hero, tracked capitals in labels.

## Pairs with

Console / table · Poster stack · Horizontal band sequence
