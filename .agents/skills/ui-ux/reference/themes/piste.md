# Theme — Piste

**Material:** snow-white paper; cold near-black ink; Barlow Condensed 800 capitals over Barlow; square edges on 2px ink rules; one cobalt used as both signal and field.
**Not when:** the page needs warmth, or the content is long-form.

## Tokens

```
paper      oklch(98% 0.004 260)     paper-2   oklch(94% 0.008 260)
ink        oklch(19% 0.014 265)     muted     oklch(48% 0.012 265)
accent     cobalt 265 · chroma 0.18            accent-ink  oklch(98% 0.006 265)
edges      radius 0 · depth none · rules 2px ink, square joins
```

## Type

- Display: Barlow Condensed 800, capitals, leading 0.94, 44–110px, 0.01em.
- Body: Barlow 400 at 16.5px / 1.55, 50–64ch.
- Figures: Barlow 600 tabular, right-aligned in tables.
- Labels: body face a step smaller, sentence case, untracked.

## Surfaces

- Cobalt is both the field and the signal: one full-width band per page, and one mark.
- Rules are 2px ink with square joins; nothing rounded, nothing dashed.
- Photographs are cold-graded, cropped tight, no radius, no caption box.
- No shadows and no texture; the snow ground stays clean.

## Range

- A conditions table: run, lift, weather — ruled rows, tabular figures.
- A pass or season card set at display size against the cobalt band.
- A route list where each stop is a ruled row with a time on the right.

## Motion

Crisp: 140ms opacity on rows. Nothing slides, nothing scales.

## Voice

Brisk, factual, current. Snow depth, lift status, opening time.

## Signature

The cobalt band: one full-width field that carries the page's single most important sentence in condensed caps.

## Avoid

Rounded corners, gradients, soft shadows, warm greys, a second accent, italic, centred hero.

## Pairs with

Console / table · Full-bleed band · Poster stack
