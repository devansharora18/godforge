# Theme — Loom

**Material:** ecru paper with sand steps; warm near-black ink; Libre Caslon Display heads and prices over Hanken Grotesk; thin rules and one ink rule; cloth photographed close in window light; one deep indigo.
**Not when:** the page is a dashboard, a game, or a demo of software.

## Tokens

```
paper      oklch(85% 0.020 80)      paper-2   oklch(89% 0.018 80)
ink        oklch(24% 0.014 60)      muted     oklch(52% 0.014 70)
accent     indigo 266 · chroma 0.12            accent-ink  oklch(96% 0.008 266)
edges      radius 0 · depth none · rules 1px thin, one 2px ink rule per page
```

## Type

- Display: Libre Caslon Display 400 at 44–84px, leading 1.02, sentence case. Prices take the same face at 32px.
- Body: Hanken Grotesk 400 at 16.5px / 1.68, 52–62ch.
- Labels: body face a step smaller, sentence case, untracked.
- The serif never goes below 28px; small type is always the grotesk.

## Surfaces

- Sand steps: three tints of the paper, never a white card.
- Cloth photographs run edge to edge and are cropped to the weave, not the object.
- One 2px ink rule per page marks the start of the commercial section.
- Hairlines elsewhere; no shadows.

## Range

- A size table: measurement, fit, price — ruled, serif figures.
- A cloth close-up at full width with three words of caption.
- A quotation set in the display face at 40px across a narrow measure.

## Motion

Quiet: 240ms opacity on images only. Text never moves.

## Voice

Precise about material and fit. Say the weave, the weight, the measurement.

## Signature

Cloth at arm's length: one photograph per page cropped so close the weave is the image, never a product shot on white.

## Avoid

White cards, rounded corners, shadows, gradients, saturated colour, centred hero, a second serif.

## Pairs with

Asymmetric split · Editorial columns · Diptych
