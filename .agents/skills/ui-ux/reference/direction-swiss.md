# Direction — Swiss grid

**Content fit:** structured, comparative, institutional, or spec-driven products. Tables, tiers, capabilities.
**Not when:** the brand is playful, or the page is a single narrative with no comparison.

## Skeleton

```
┌ 12 columns, visible rule ─────────────────┐
│ wordmark      index  index  CTA           │
├────────────┬──────────────────────────────┤
│ 01         │ Headline spans 8 columns     │
│            │ ──────────────────────       │
│            │ body 4 cols      meta 2      │
├────────────┴──────────────────────────────┤
│ spec        │ spec        │ spec          │
└───────────────────────────────────────────┘
```

Sections: grid hero → comparison table → numbered capability rows → spec sheet → colophon.

## Type

- One neo-grotesk family for everything: Archivo, Söhne, Aeonik, General Sans, Neue Haas Grotesk. Never Inter.
- Display at clamp(3rem, 7vw, 7rem), tight tracking (−0.03em), line height 0.95.
- Body 15–16px, 1.5, flush left. No centered paragraphs.
- Numerals and labels in the same family, tabular figures for tables.

## Color

- Paper white or a single off-white; black type; one signal colour (red, blue, or green) used for state and links only.
- No gradients, no tinted sections. Separation is rules and space.

## Texture

The grid itself is the texture: visible column rules, baseline marks, oversized section numerals in the margin, hairline tables.

## Motion

Minimal. Load sequence: type rises in two steps, content fades. Hover: underline, 120ms. Nothing scroll-linked.

## Signature

A visible grid or a 01–06 numeral column that persists across sections. The restraint must look engineered, not empty.

## Avoid

Centered hero, decorative serif, shadows, rounded cards, icon circles, colour used decoratively, more than one family.
