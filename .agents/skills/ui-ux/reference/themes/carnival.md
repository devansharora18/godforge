# Theme — Carnival

**Material:** tinted paper; deep warm ink; Big Shoulders Display 800 capitals set poster-large over Golos Text; 2px rules; a hard 4px ink shadow; two accents that compete as whole fields.
**Not when:** the page asks for trust, silence, or a decision that costs money.

## Tokens

```
paper      oklch(86% 0.050 50)      paper-2   oklch(90% 0.040 50)
ink        oklch(20% 0.030 45)      muted     oklch(46% 0.030 45)
accent     yellow 95 · chroma 0.17  second  magenta 350 · chroma 0.16
edges      radius 0 · depth hard 4px offset · rules 2px ink
```

## Type

- Display: Big Shoulders Display 800, capitals, leading 0.88, 48–160px. It carries the page.
- Body: Golos Text 400 at 17px / 1.5, 50–62ch, mostly one column.
- Labels: body face a step smaller, sentence case, untracked.
- Two type sizes above 48px per screen, no more.

## Surfaces

- Every panel casts 4px of solid ink at a 45° offset, no blur, no spread.
- Accents appear as whole fields, never as a line or an outline: one yellow band, one magenta band.
- Rules are 2px and always meet their corner.
- Photographs sit inside a band, cropped square, no rounding.

## Range

- A schedule set as a poster: day, time and name, each a line in the display face.
- A price in two fields, one yellow one magenta, with the figure reversed out.
- A lineup where each act gets a band of equal height across the width.

## Motion

One entrance for the head: 220ms drop of 24px with the shadow snapping with it. Nothing else moves, ever.

## Voice

Loud, particular, named. Say the act, the date, the door time — never "an unforgettable evening".

## Signature

The hard offset shadow: every block sits 4px above a slab of solid ink, so the page looks printed in two passes.

## Avoid

Three accents, blurred shadows, rounded corners, italic, a quiet hero, grey anywhere in the type.

## Pairs with

Poster stack · Horizontal band sequence · Full-bleed band
