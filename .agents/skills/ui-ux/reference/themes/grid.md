# Theme — Grid

**Material:** white poster stock; blue-black ink; Radio Canada Big 700 in sentence case over Radio Canada; flat fields of ultramarine and one Swiss red mark; no strokes.
**Not when:** the page needs warmth, texture, or a personality the grid cannot carry.

## Tokens

```
paper      oklch(97% 0.004 250)     paper-2   oklch(93% 0.008 250)
ink        oklch(21% 0.030 265)     muted     oklch(52% 0.020 265)
accent     ultramarine 266 · chroma 0.19      accent-ink  oklch(98% 0.006 266)
edges      radius 0 · depth none · rules none, fields instead
```

## Type

- Display: Radio Canada Big 700 at 40–96px, leading 1.0, −0.02em, sentence case.
- Body: Radio Canada 400 at 17px / 1.55, 50–68ch.
- Labels: body face a step smaller, sentence case, untracked. Never capitals.
- One weight per role; no italic.

## Surfaces

- Fields, not rules: a section is delimited by a flat ultramarine block, not a line.
- One red mark per page — a square, a word, a single rule. Never two.
- No strokes, no shadows, no radius; the edge of a field is the edge.
- Photographs butt against the column edge, never inset, never rounded.

## Range

- A three-column figure row where each column is a field and a number.
- A definition list where terms sit in the first column and never wrap.
- A full-bleed ultramarine band holding one sentence at display size.

## Motion

Fast and flat: 160ms opacity, no translation, no scale. The grid carries the composition.

## Voice

Sober, comparative, quantitative. Say what is larger, older, or cheaper, and by how much.

## Signature

The visible column field: content blocks align to a 12-column measure that is only revealed where an ultramarine block meets its edge.

## Avoid

Strokes, shadows, rounded corners, centred hero, a second red element, texture, gradients.

## Pairs with

Asymmetric split · Console / table · Full-bleed band
