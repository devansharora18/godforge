# Theme — Empyrean

**Material:** smoked umber-black ground; bone-white ink; Cinzel capital inscriptions over Work Sans; brass rules as the only metal; one band of full bone light.
**Not when:** the page is a product tour, a dashboard, or aimed at children.

## Tokens

```
ground     oklch(14.5% 0.012 55)    surface   oklch(19% 0.014 55)
ink        oklch(95% 0.014 80)      soft      oklch(75% 0.020 75)
brass      oklch(78% 0.110 85)      brass-ink oklch(18% 0.025 85)
edges      radius 0 · depth none · rules 1px umber, brass only for frames
band       bone oklch(94% 0.014 80) · ink on band oklch(15% 0.012 55)
```

## Type

- Display: Cinzel 600, capitals by design, leading 1.06, 40–104px, 0.01em. It is an inscription, not a voice.
- Body: Work Sans 400 at 16.5px / 1.65, 54–66ch.
- Figures and paths: JetBrains Mono 400 at 12–14px, tabular.
- Labels: Work Sans 13px, sentence case, untracked. Cinzel never sets a label.

## Surfaces

- No radius anywhere; the edge of a surface is a 1px rule, never a shadow.
- The tablet: two brass rules 6px apart holding one command or one figure.
- One bone band per page at most: the page's only full-light surface, and the only place ink reverses.
- Brass is metal, not paint: frames, one numeral, one hover. Never a large fill.
- No glow, no halo, no radial light, no gradient. Light comes from the bone band and the type scale.

## Range

- An inscription line at 96px holding a whole screen on its own.
- A ruled ledger of names, folios and counts.
- A tablet holding one command, framed twice.
- A single reversed band of one sentence between two dark sections.

## Motion

A plaque does not move. A 300ms opacity fade on the hero, opacity only on hover, and nothing else.

## Voice

Declarative, engraved, present tense. State the fact and its number. Never an exclamation mark.

## Signature

The tablet: the install command set inside a double brass rule, framed like an object rather than a code sample.

## Avoid

Glow, halos, gradients, gold covering more than a frame's width, rounded corners, drop shadows, Cinzel below 32px, a second bone band, centred hero, a blue or cool-grey ground.

## Pairs with

Oversized type · Editorial columns · Ledger / index
