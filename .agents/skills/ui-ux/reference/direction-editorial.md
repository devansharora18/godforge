# Direction — Editorial

**Content fit:** a document, manifesto, essay, archive, library, or any product whose value is written down.
**Not when:** the product is a live demo, a dashboard, or a game.

## Skeleton

```
§ 01 — eyebrow · mono
Huge serif headline, second line italic
─────────────────────────────────────────
body 47ch                     artifact or index
─────────────────────────────────────────
01  entry ...................... note
02  entry ...................... note
```

Sections: ledger hero → numbered list → margin spread → full-bleed quote → colophon. Never a card grid.

## Type

- Display: high-contrast serif — Instrument Serif, Fraunces, Newsreader, Bricolage. Italic carries the second voice.
- Body: grotesk (Instrument Sans, General Sans) at 16–17px, 1.6 line height, 47–65ch.
- Labels: mono, 10–11px, uppercase, 0.18em tracking.
- Contrast between display and body must be obvious. A 2px size difference is not a hierarchy.

## Color

- Warm paper (`#F4F0E7`, `#EFEAE0`), near-black ink (`#16130F`), hairlines at 12–18% ink.
- One accent only: ember, oxblood, forest. It marks state, never decoration.
- Dark mode is obsidian (`#0C0B09`), not an inverted white page.

## Texture

Faint grain (2–4%), dotted leaders, folios, Roman or two-digit numerals, rules that stop short.

## Motion

Quiet. 400–600ms fades, 12–24px rise, one stagger for the headline block. No parallax, no pinned scenes.

## Signature

A numbered index that expands inline with real content — not a card grid with numbers on it.

## Avoid

Cards, pill buttons, gradient atmosphere, stock photography, all-serif body copy, centered layouts, more than one accent.
