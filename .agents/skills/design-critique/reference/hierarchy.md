# Hierarchy

Hierarchy is the order in which the eye is allowed to move. Test it before commenting on anything else.

## Four tests

1. **Squint** — blur the screenshot to 10%. What remains? If two things remain and neither is the action, the hierarchy is split.
2. **Five seconds** — show it for five seconds, then ask what the page is and what to do. If the answer needs a second look, the headline or the CTA is too quiet.
3. **Grayscale** — remove color. If the structure collapses, color was carrying it.
4. **Screenshot at 360** — if the hierarchy only works on desktop, it is a layout, not a hierarchy.

## The levers, in order of strength

1. **Position** — top-left and the first screenful outrank everything.
2. **Size** — a 2× jump reads; a 1.2× jump is noise.
3. **Weight** — 600 against 400 is visible; 500 against 400 is not.
4. **Space** — isolation creates hierarchy more reliably than bold.
5. **Color** — one accent, used once, beats five tinted elements.
6. **Decoration** — borders, icons, shadows. Weakest; never the only signal.

## Common defects

- Three elements at the same weight competing above the fold.
- A headline and a subhead with no size or weight gap.
- Equal spacing between all groups, so nothing binds.
- Section headings that are smaller than body copy.
- A CTA that matches the nav link weight.
- Every section opening the same way (eyebrow, heading, paragraph, three cards). Rotate openings.
- Content centered by default, removing the left edge the eye scans.

## Typography specifics

- Five or six sizes; if you count nine, it is not a scale.
- Display 48–120px, body 15–17px, labels 10–12px. The middle is where hierarchy dies.
- Measure 45–75ch. Wider than 80 and the eye loses the line.
- Line height 1.1–1.3 display, 1.5–1.65 body.
- Letter spacing negative on large type, positive on caps labels.
