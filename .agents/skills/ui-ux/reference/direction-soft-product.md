# Direction — Soft product

**Content fit:** consumer apps, onboarding, health, personal finance, education, marketplaces.
**Not when:** the product is a developer tool or the audience expects technical density.

## Skeleton

```
┌──────────────────────────────────────────┐
│ wordmark            product   pricing    │
│                                          │
│        one friendly line                 │
│        [ primary action ]                │
│        ┌ real product preview ─────────┐ │
│        │ rounded, actual UI            │ │
│        └───────────────────────────────┘ │
├──────────────────────────────────────────┤
│  text block     │     illustration       │
│  (alternating)  │     (alternating)      │
└──────────────────────────────────────────┘
```

Sections: centered hero with a real product image → alternating feature blocks → one testimonial with a name → pricing preview → colophon.

The centered hero is allowed here only with a real interface asset.

## Type

- One geometric or humanist sans: Bricolage Grotesque, DM Sans, Plus Jakarta Sans, Satoshi.
- Display 40–64px, body 16px/1.6. Rounded punctuation is fine; rounded *type* is not.
- Labels in sentence case; avoid the mono-label habit.

## Color

- Warm neutral field (cream, sand, pale grey) plus one saturated friendly accent and one pastel support.
- Gradients only inside the product preview, never as page atmosphere.
- Cards use one radius (12–20px) and one soft shadow, consistently.

## Texture

Illustration system or product UI; no grain, no rules-by-default, no ASCII. Depth from a single elevation level.

## Motion

Playful but short: 200ms spring on cards, one 400ms hero settle, staggered feature reveals. Nothing bounces twice.

## Signature

One illustration system or a single product moment shown large — the empty state, the first win, the actual chart.

## Avoid

All-caps mono labels, brutalist borders, dense tables, three-feature-card rows, stock photography of people at laptops.
