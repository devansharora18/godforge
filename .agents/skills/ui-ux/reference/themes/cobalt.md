# Theme — Cobalt

**Material:** cool near-white paper; blue-grey ink and hairlines; Familjen Grotesk over IBM Plex Sans; a generated ASCII field on an 8×16 cell; keycaps and cut-corner panels; JetBrains Mono on graphite; one electric cobalt.
**Not when:** the page is editorial, warm, or about a physical object.

## Tokens

```
paper      oklch(97% 0.006 250)     paper-2   oklch(93% 0.010 250)
ink        oklch(28% 0.030 250)     muted     oklch(54% 0.020 250)
accent     cobalt 256 · chroma 0.20             accent-ink  oklch(98% 0.006 256)
graphite   oklch(24% 0.010 250)     edges radius 10px cut corners · rules 1px
```

## Type

- Display: Familjen Grotesk 700 at 36–72px, leading 1.04, sentence case.
- Body: IBM Plex Sans 400 at 16.5px / 1.6, 54–66ch.
- Code and measurements: JetBrains Mono 400 at 13px, on graphite for blocks.
- Labels: body face a step smaller, sentence case, untracked.

## Surfaces

- Cut corners: panels lose a 10px corner rather than rounding, one corner only.
- The ASCII field is generated, 8×16 cells, dim, behind the hero only.
- Keycaps for anything pressable: 2px bottom edge, 4px radius, no shadow.
- Hairlines at 10% ink; nothing else is bordered.

## Range

- A request and response pair: graphite block above, answer below.
- A three-step integration list where each step is a keycap numeral.
- A price with the cobalt as a single underline, not a fill.

## Motion

Snappy: 140ms on keycap press, 200ms opacity on blocks. No bounce.

## Voice

Practical, technical, confident. Say the endpoint, the limit, the time.

## Signature

The cut corner: every panel is clipped at one corner, so the page reads as machined panels rather than cards.

## Avoid

Rounded cards on all four corners, gradients, soft shadows, warm greys, a second accent, centred hero.

## Pairs with

Console / table · Asymmetric split · Horizontal band sequence
