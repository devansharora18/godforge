# Theme — Ink

**Material:** white paper; a black with no hue; Epilogue 700 over Epilogue 400; hairline rules and state pills; one teal that means "in".
**Not when:** the page needs texture, warmth, or more than one colour idea.

## Tokens

```
paper      oklch(99% 0 0)           paper-2   oklch(96% 0 0)
ink        oklch(14% 0 0)           muted     oklch(50% 0 0)
accent     teal 190 · chroma 0.11             accent-ink  oklch(97% 0.008 190)
edges      radius 4px surfaces, 999px state pills · depth none · rules 1px
```

## Type

- Display: Epilogue 700 at 36–80px, leading 1.02, −0.025em, sentence case.
- Body: Epilogue 400 at 16.5px / 1.6, 56–68ch.
- Labels: body face a step smaller, sentence case, untracked.
- One family, two weights, no third size above 32px.

## Surfaces

- Hairlines at 10% ink; a section is separated by a rule, never a fill.
- State pills are the only rounded, filled elements on the page.
- Photographs appear once, cropped to a 4:3 rectangle with 4px radius, no caption.
- Zero chroma everywhere except the accent, which is the point.

## Range

- A price table with the state pill beside the available plan.
- A single sentence at 64px occupying the whole screen.
- A three-row comparison where only one cell carries the teal.

## Motion

180ms on opacity and colour only. Nothing translates; the page feels like a document.

## Voice

Exact, unadorned, declarative. A claim carries its number or it is cut.

## Signature

The teal that only ever means one thing — available, in stock, on. It never decorates anything else.

## Avoid

A second colour, a shadow, texture, gradients, rounded cards, a tracked label, centred hero.

## Pairs with

Console / table · Asymmetric split · Colophon close
