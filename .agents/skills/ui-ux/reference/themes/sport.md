# Theme — Sport

**Material:** cool concrete paper; blue-black ink; uppercase Saira Condensed over Albert Sans; condensed figures and mono times; two-weight rules; one volt fill.
**Not when:** the page needs softness, craft, or a slow read.

## Tokens

```
paper      oklch(91% 0.006 250)     paper-2   oklch(86% 0.008 250)
ink        oklch(22% 0.020 265)     muted     oklch(50% 0.014 265)
accent     volt 120 · chroma 0.19 · L 86        accent-ink  oklch(20% 0.03 120)
edges      radius 0 · depth none · rules 4px and 1px, nothing between
```

## Type

- Display: Saira Condensed 700, uppercase, leading 1.0, 32–88px, 0.02em.
- Body: Albert Sans 400 at 16.5px / 1.55, 52–64ch.
- Times and scores: JetBrains Mono 500, tabular, so columns line up.
- Labels: body face a step smaller, sentence case, untracked.

## Surfaces

- Two rule weights only: a 4px ink rule above a section, 1px hairlines inside it.
- The volt fill appears as one bar per screen, behind a result or a time.
- Photographs are cropped to the action, cool grade, no radius, no caption box.
- Nothing rounded, nothing floating; content sits on the rule.

## Range

- A results table: position, name, time — mono figures, ruled rows.
- A fixture list where the date is the volt bar.
- A single number at 88px with the qualifying mark beside it in body size.

## Motion

Fast: 140ms opacity on result rows only. No lift, no scale, no counters ticking.

## Voice

Numeric, clipped, factual. Times and distances, not adjectives.

## Signature

The mono results column: every figure is monospaced and right-aligned, so the page reads like a timing sheet.

## Avoid

Rounded corners, gradients, soft shadows, colour photography, italic, a second accent, centred hero.

## Pairs with

Console / table · Poster stack · Horizontal band sequence
