# Direction — Collage

**Content fit:** studios, communities, zines, portfolios, creative tools, cultural archives.
**Not when:** the product must prove reliability, pricing clarity, or compliance.

## Skeleton

```
┌──────────────────────────────────────────┐
│  ┌────────┐   headline, two lines   ┌──┐ │
│  │ card A │   ↖ rotated 2°          │C │ │
│  └────────┘        ┌──────────┐     └──┘ │
│        ┌───────────│  card B  │          │
│        │  overlaps └──────────┘          │
├──────────────────────────────────────────┤
│  fragment   fragment   fragment  fragment│
└──────────────────────────────────────────┘
```

Sections: layered hero → overlapping proof strip → alternating story blocks → index → colophon.

## Type

- Three families maximum, deliberately mismatched: a serif, a mono, and a grotesk. Each has a job.
- Sizes jump: 12px labels next to 120px statements. Rotation only on labels or cards, never body copy.
- Handwritten only if it is a real asset, never a font pretending to be.

## Color

- A neutral field (paper, bone, or a deep tone) plus four to six accents used as blocks, not gradients.
- Colour marks ownership: each fragment has a colour that identifies its source.

## Texture

Torn edges, tape strips, halftone crops, cut-out shapes, thin rules, real screenshots at odd crops. Layer order must be readable, not chaotic.

## Motion

Small and physical: cards settle 4–8px with 60ms stagger, one 2° rotation on hover. No infinite marquees of content the user needs.

## Signature

A layering system where overlaps carry meaning — chronology, source, or hierarchy — rather than random rotation.

## Avoid

Strict 12-column symmetry, a single typeface, minimalism as a goal, glass, gradients, more than six accents, unreadable overlaps.
